# Chat Café tiles

These in-product sprite crops are derived from Gherwit's free 16×16 pixel-art packs:

- [CAFE TILES - FREE](https://gherwit.itch.io/cafe-tiles-16x16)
- [CITY TILES - FREE](https://gherwit.itch.io/city-tiles)

The author permits use and modification in commercial and non-commercial projects. The assets may not be resold, reposted as raw asset packs, or claimed as original work. Credit is optional and appreciated.

The repository contains only the small sprites used by the Agents Office Tower Chat Café scene, not the original source sheets or archives.
